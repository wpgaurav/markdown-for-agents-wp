# Markdown for Agents (WordPress)

[![Buy me a coffee](https://img.shields.io/badge/Buy%20me%20a%20coffee-FFDD00?style=flat&logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/gauravtiwari)

_No Cloudflare Pro or Business or Enterprise required._ This MU-plugin serves clean markdown to AI agents that send Accept: text/markdown.

Drop in wp-content/mu-plugins/.

## Support This Project

This MU-plugin is open source under GPL-2.0 and it lets your WordPress site serve clean Markdown to AI agents that send an Accept: text/markdown header.
